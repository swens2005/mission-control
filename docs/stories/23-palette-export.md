# 23. Palette Lab: export tokens

As a studio admin, I want to export the kit in the formats a build uses,
so nobody retypes hex values.

## Acceptance criteria

- [x] Three exports, generated by pure functions from the kit:
    - **CSS custom properties** (`:root { --ink: #10233a; ... }`, with the
      OKLCH value in a comment and the type scale as `--text-*`);
    - a **Tailwind 4 `@theme` block** (`--color-*`, `--font-*`,
      `--text-*`);
    - **design tokens JSON** in the W3C Design Tokens format
      (`$type`, `$value`).
- [x] Each export is shown in a code block with **Copy** (clipboard API,
      with a visible "Copied" status) and **Download** (an authorized
      route that sends the file with `Content-Disposition: attachment`).
- [x] Token names are slugs of the color names, unique within the kit.
- [x] `data-tour`: `export-tabs`, `copy-export`.

## Tests

- [x] Unit: each format for a small kit, compared with expected output
      (snapshot-style strings), including name slugging and duplicates.
- [x] Download works for the studio, 404 for other workspaces.
